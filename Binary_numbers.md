Provide evidence, then save before moving on.

1.1 - Convert 234 (which is in base-10) to its binary form. (2 marks)

234 = 11101010
evidence : 234 / 2 = 117 remainder 0
117 / 2 = 58 remainder 1
58 / 2 = 29 remainder 0
29 / 2 = 14 remainder 1
14 / 2 = 7 remainder 0
7 / 2 = 3 remainder 1
3 / 2 = 1 remainder 1
1 / 2 = 0 remainder 1
we write the remainders from last to first to get the binary of 234

1.2 - Convert the following binary number 11011110 to its decimal form. (2 marks)

11011110 = 222
evidence : the binary digits are 8 bits we write the place values of powers of 2 which will be 128 64 32 16 8 4 2 1 we then add where the place values is 1 which is 128 + 64 + 16 + 8 + 4 + 2 = 222
