1.1 - Assume that b > cd, if c is replaced with -c does the property still hold? (2 marks)

no, not necessarily.for example let b=0, c=-1, d=1. Then (b>cd) is (0>-1), which is true. Replacing (c) with (-c) gives (0>1), which is false
