1.1 – What is a calculated field in a PivotTable? (2 marks)

a calculated field is a field in a pivottable that uses a formula to calculate values from other fields in the source data

1.2 – Write the formula to calculate profit using revenue and total cost. (2 marks)

= revenue - total cost

1.3 – How would you calculate profit margin from profit and revenue? (2 marks)

profit margin = profit / revenue * 100  

1.4 – Describe how to add a calculated field to a PivotTable. (2 marks)

select a cell in the Pivottable, then choose pivottable Analyze, click Fields, Items & Sets then Calculated Field. in the dialog box enter a name in the name fields, enter the formula in the Formula field double click the fields below to insert them, select ok and a new field will appear in the pivottable value area
