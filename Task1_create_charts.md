Task 1: Create a Chart

1.1 – If you wanted to represent a part of a whole, which chart would be the most appropriate? (1 mark)

A pie chart.

1.2 – Which chart would be the most appropriate to represent the revenue that different categories of food generated? (1 mark)

A column chart, because it makes it easy to compare revenue across categories.

1.3 – When using a line chart, what data would typically be shown along the horizontal axis? (1 mark)

Time periods, such as days, months, or years.

1.4 – When is a pie chart not a good choice for displaying data? (1 mark)

When there are many categories, values are very similar, or the data does not represent parts of a meaningful whole.

1.5 – What does each point along the line in a line chart represent? (1 mark)

A data value for a particular category or time period, plotted against the horizontal and vertical axes.
