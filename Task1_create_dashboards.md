Task 1: Create Dashboards
Provide evidence, then save before moving on.

1.1 – Define a dashboard in spreadsheet data analysis. (2 marks)

A dashboard is a single organised spreadsheet view that key data, metrics, and visualisations so that important information can be understood 

1.2 – List three components you would include on a business dashboard. (3 marks)

- Key perfomance indicators (KPIs)
- Charts and graphs
- Filters and slicers

1.3 – Explain why dashboards help management make decisions. (2 marks)

Dashboards present important measures and trends together, helping managers quickly monitor performance, spot changes or problems and compare results with targets. Filters let them examine the data by relevant categories supporting informed decisions.
