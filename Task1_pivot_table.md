Task 1: Pivot Table
Provide evidence, then save before moving on.

1.1 – What is a pivot table? (1 mark)

A pivot table summarizes and reorganizes data so you can analyze it.

1.2 – List the four essential field types. (4 marks)

Rows, columns, values and filters.

1.3 – Explain two of the golden rules of data preparation. (2 marks)

For columns use one variable per column so the data can correctly be interpreted and analyzed. use one row for each record so it can be easier to sort, filter and summarize.

1.4 – What is the recommended chart for trend lines? (1 mark)

A line chart is recommended as it shows trends over time.

1.5 – What is the recommended chart for plotting relationships? (1 mark)

A scatter plot as it shows relationships between two variables.

1.6 – Which chart is appropriate for understanding data spread? (1 mark)

A histrogram is appropriate for understanding the the spread or distribution of data.
