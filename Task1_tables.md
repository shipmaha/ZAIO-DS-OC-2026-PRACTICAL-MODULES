Task 1: Tables
Provide evidence, then save before moving on.

1.1 – What information should go in the header row of a table? (1 mark)

The header row should contain the  descriptive label for each column, identifying the type of information below it.

1.2 – Provide instructions on how to change the header row colour. (1 mark)

 Select the header row, right click and go to table properties or click Format + table + table options.

1.3 – Provide the hexadecimal colour code for white. (1 mark)

 #FFFFFF

1.4 – Provide instructions on how get alternating rows in a table. (1 mark)

Select the table, open its formatting options and enable Alternating colours.

1.5 – What does “Create group by view“ do? (1 mark)

It creates a separate view that groups the table’s rows by values in a chosen column, making related records easier to view.
